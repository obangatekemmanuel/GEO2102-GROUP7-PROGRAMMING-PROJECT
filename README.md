# GEO2102-GROUP7-PROGRAMMING-PROJECT
GROUP7 Programming project is 'Reduced Level Calculator' which uses both the height of collimation and 'Rise and Fall' methods to compute the reduced levels, applies corrections and provides the arithmetic checks. Then a csv file of results is exported.
